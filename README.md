# 🧠 AI Mental Wellness App

### GenAI Hackathon Project (Frontend Prototype)

An AI-powered mental wellness **frontend prototype** developed during a **GenAI Hackathon**, focused on user experience, AI interaction flows, and mental wellness feature design.

---

## 🚀 Project Overview

The AI Mental Wellness App demonstrates how AI-driven concepts can be applied to mental well-being through a modern, interactive web interface.

The project focuses on:

* Mental wellness user journeys
* AI chatbot interaction interface
* Mood tracking visualizations
* Guided wellness and breathing experiences

> ⚠️ **Note:** This is a **frontend-only hackathon prototype**. Backend services, database integration, and deployment were not implemented within the hackathon timeframe.

## ⚙️ How to Run the Project Locally

### Prerequisites

* Node.js (v18 or above recommended)
* npm

### Steps

```bash
# Clone the repository
git clone https://github.com/Algode18/AI_Mental_Wellness_App.git

# Navigate to the project directory
cd AI_Mental_Wellness_App

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will run locally at:

```
http://localhost:3000
```
